# Support

PicoTracker is an open-source embedded hardware and firmware project, not a commercial support service. Public support is handled through the repository where possible so answers remain useful to future contributors.

## Where to ask

Use a GitHub issue for:

- reproducible firmware or tooling problems;
- build, test, or decoder failures;
- unclear or outdated documentation;
- questions tied to a specific PicoTracker file, release, or hardware revision.

Before opening an issue, search the existing issues and documentation. Include the commit or release, host environment, relevant hardware revision, exact reproduction steps, and logs or measurements where available.

For proposed code or documentation changes, follow [`CONTRIBUTING.md`](CONTRIBUTING.md) and keep pull requests narrowly scoped.

For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) and do not disclose exploitable details in a public issue.

Historical hardware files are retained for reference and component availability changes over time, so current sourcing questions may require independent revalidation rather than a definitive maintainer answer.
