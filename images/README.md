# Project images

This directory contains historical hardware photographs and development screenshots used by the PicoTracker documentation.

Image filenames use lowercase kebab-case with lowercase extensions, for example `hc12-component.jpg`. The `readme/` subdirectory contains smaller, optimized copies used on the repository landing page; the full-resolution source photographs remain in this directory.

When adding a new image, use a descriptive lowercase filename, avoid spaces and underscores, and update any documentation links in the same change.
